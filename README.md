# 个人主页

一个面向国内与海外招聘的双语 Technical Artist 个人作品集。

## 当前内容

- 中英双语切换
- TA 求职定位与天津求职状态
- Unity、Shader、C#、AI × TA 能力方向
- 四个真实 Unity Shader/VFX 实践项目
- 蓝紫天空与实时渲染视觉氛围
- 鼠标视差、滚动揭示和响应式动效
- 桌面端、平板和手机端响应式布局

## 后续替换

`public/projects/`，全局视觉样式位于 `app/globals.css`。后续阶段将添加项目详情页与真正的 WebGL 3D 场景。
